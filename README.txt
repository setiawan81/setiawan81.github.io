YOGI SETIAWAN - BLOG PRIBADI

Cara mempublikasikan blog ke GitHub Pages:
1. Pastikan semua perubahan sudah disimpan (gunakan editor di admin.html).
2. Buka Terminal / Git Bash di folder ini.
3. Jalankan perintah Git berikut:
   git add .
   git commit -m "Update blog baru"
   git push origin main
4. GitHub Pages akan otomatis memperbarui situs Anda dalam beberapa detik.

Edit utama:
- index.html: profil, tulisan, email, dan tautan sosial
- assets/style.css: warna dan tampilan
- posts/: halaman artikel
- admin.html: halaman editor tulisan visual lokal
